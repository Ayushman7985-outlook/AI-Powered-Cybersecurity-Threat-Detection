# Local dataset files

Obtain the UNSW-NB15 dataset from the official source: https://research.unsw.edu.au/projects/unsw-nb15-dataset

Place `UNSW_NB15_training-set.csv` and `UNSW_NB15_testing-set.csv` in this directory. CSVs are intentionally ignored by Git; confirm redistribution terms before sharing them. See the repository README for attribution and validation instructions.
